# Sysmac Project Interpretation

> [!IMPORTANT]
> **100% AI-generated.** All code, helper scripts, skill instructions, documentation, and tests in this repository were generated by AI at the repository owner's direction. Passing AI-generated tests does not constitute independent engineering review or native Sysmac/PLC validation.

A ChatGPT and Codex plugin for interpreting saved Omron Sysmac Studio projects with traceable source evidence.

The plugin includes a reusable skill, focused interpretation references, and a Python helper that decodes `.smc2` archives, searches extracted source, and compares revisions. Source projects are read without modification.

## Install from GitHub

Register this repository as a plugin marketplace:

```text
codex plugin marketplace add INVAREX/sysmac-project-interpretation
codex plugin add sysmac-project-interpretation@sysmac-github
```

Restart ChatGPT desktop after installation, start a new conversation, and select **Sysmac Project Interpretation** from the `@` menu. Actual availability depends on client and workspace policy.

The repository contains `.agents/plugins/marketplace.json` and a plugin under `plugins/sysmac-project-interpretation/`. The marketplace resolves its plugin path relative to the repository root, so a Git-backed installation can use its managed checkout rather than an unrelated working folder.

## Use

Provide a project accessible to the session and a specific question. For example:

> Interpret this Sysmac project. Identify scheduled programs and trace the work-order sequence, including cancellation and restart. Support findings with the source hash, entity paths, and rung locations.

Other supported requests include explaining ladder and inline ST, tracing FB/UDT dependencies, reviewing PLC/HMI bindings, and comparing revisions.

Raw archive decoding requires file access and Python 3.10 or later in the session. A session without those tools can interpret supplied readable exports or decoded evidence and must state its coverage limits. The plugin does not require a separate hosted server or an OpenAI API key.

## Run the helper directly

From this repository root:

```text
python plugins/sysmac-project-interpretation/skills/sysmac-project-interpretation/scripts/sysmac_project.py decode project.smc2 --out decoded/review
python plugins/sysmac-project-interpretation/skills/sysmac-project-interpretation/scripts/sysmac_project.py find decoded/review Work_Order
python plugins/sysmac-project-interpretation/skills/sysmac-project-interpretation/scripts/sysmac_project.py compare decoded/old decoded/new --out decoded/comparison.json
```

Add `--hmi` to `decode` when HMI dependencies are relevant. Run `--help` for device selection, explicit rename mappings, and extraction limits. The helper uses only Python's standard library.

## Validate

```text
python -B scripts/validate_repository.py
python -B -m unittest discover -s plugins/sysmac-project-interpretation/skills/sysmac-project-interpretation/scripts -p "test_*.py" -v
```

The helper tests cover extraction fidelity, unchanged source archives, NA variable maps, malformed/partial content, geometry and edge changes, explicit renames, output isolation, and evidence hashes. These checks do not establish native Sysmac compilation, HMI runtime correctness, or PLC execution. End-to-end plugin invocation should be tested in a new ChatGPT conversation after installation.

## Package boundaries

This plugin interprets saved project evidence. It does not decrypt protected code, generate native project edits, operate physical controllers, or validate safety functions. Unsupported content and external dependencies must remain explicit in findings.
